# Рисование в MacPaint через Codex и MCP

Локальный прототип реализован 16 октября 2026 года в ветке `mod`. Подключение описано в [инструкции для Cursor, Codex и Claude Code](../AI-MCP-setup.md). Ветка остаётся локальной.

## Пользовательский сценарий

Один раз подключить локальный MCP-сервер MacPaint к приложению Codex. В дальнейшем:

1. Открыть модифицированный MacPaint.
2. В About включить `Enable mods`, затем в меню `Mods` включить `AI control`.
3. Сказать Codex: «Нарисуй дом с трубой, двумя окнами и деревом справа».
4. Codex получает изображение и состояние холста, составляет команды и рисует в открытом документе MacPaint.
5. Продолжить: «Сделай окна больше», «Подними крышу», «Добавь дым». Codex проверяет результат и вносит правки.
6. Результат можно поправить вручную, отменить средствами MacPaint и сохранить в обычный `.mac`.

Схема: пользователь → Codex → локальный MCP-сервер MacPaint → открытый холст.

## Устройство

Понимание запросов и выбор действий остаются в Codex. MacPaint предоставляет инструменты чтения холста, рисования и отмены. Отдельный AI-клиент и ключ API внутри MacPaint для этого сценария не нужны.

Встроенный `MacPaint.app/Contents/MacOS/MacPaintMCP` запускается клиентом как STDIO-сервер. Это дополнительная точка входа нативного executable, которая не создаёт окно. Helper связывается с открытым редактором через Unix-сокет `/private/tmp/macpaint-mcp-<uid>/control.sock`. Каталог имеет права `0700`, сокет `0600`, обе стороны проверяют UID соединения. Файловая блокировка допускает управление одним экземпляром редактора.

Команды используют `PaintModel`, `Bitmap`, исходные шрифты и геометрию QuickDraw. Изменения выполняются в главном потоке, обмен по сокету проходит в фоне. Helper поддерживает STDIO JSON-RPC и согласование MCP `2024-11-05`, `2025-03-26`, `2025-06-18`, `2025-11-25`.

## Минимальные инструменты

- `get_canvas`: изображение холста, размер страницы, видимая область, выделение и состояние документа.
- `draw_batch`: ограниченный пакет поддерживаемых действий — штрихи, линии, фигуры, заливка и текст. Один пакет соответствует одному шагу существующей отмены.
- `undo`: отмена последнего пакета по правилам MacPaint. Сохранить существующую одноуровневую отмену; цепочка пакетов не обещает многоуровневую историю.
- `new_document`, `open_document(path)`: создают/открывают отдельный документ без потери текущего. Уже открытый путь активирует существующий документ.
- `save_document`, `save_as(path)`: сохраняют MAC самим приложением и обновляют имя/dirty. `save_document` без пути сохраняет в текущий файл.
- `export_png(path)`: экспортирует всю страницу, сохраняя имя/dirty/Undo.
- `list_documents`, `switch_document(document_id)`: список и переключение до 16 документов с независимыми моделями, Undo и viewport. ID действуют в одной сессии.

Команды работы с документами добавлены 20 октября 2026 года по списку из отчёта Happy Mac.
Пути абсолютные, родительская папка должна существовать. Для замены существующего файла по новому пути нужен `overwrite:true`;
сохранение в текущий MAC обновляет его без флага. Файлы других открытых документов защищены от перезаписи.
Ошибки чтения/записи и валидации сохраняют текущий рисунок. Входной MAC ограничен 1 МБ.
Неактивный документ хранит целиком `PaintModel` и свой `RecoveryStore`; переключение не превращает рисунок в новый bitmap и не теряет Undo.
**Mods → Next Document** переключает рисунки вручную; Close показывает оставшийся документ, выход проверяет все несохранённые рисунки.

Координаты задавать в пикселях документа с началом в левом верхнем углу. Масштаб окна, его положение и прокрутка не должны менять результат команды. Для частичных исправлений Codex заново смотрит холст и использует доступные операции выделения и рисования; редактирование отдельных объектов потребовало бы отдельного решения, поскольку документ растровый.

## Интерфейс и поведение

Все дополнительные команды находятся в `Mods`, последнем меню после `Style`. Управление через MCP доступно только при включённых `Enable mods` и `AI control`. При выключении управления новые команды отклоняются, текущую операцию можно остановить без повреждения рисунка.

Редактор показывает прогресс и кнопку Stop. Escape и Mods → Stop AI Drawing тоже останавливают пакет между действиями. Завершённые действия остаются одним шагом Undo. Ручное рисование заблокировано на время пакета. Переключатели сохраняются в настройках приложения; формат `.mac` остаётся прежним. Режим Macintosh 128K проверяет приблизительный бюджет памяти перед пакетом. Заливка связной области может быть отклонена из-за размера рабочего буфера.

Автоматизация мышью через экран подходит для демонстраций и проверки результата. Для регулярного рисования предпочтителен MCP: команды используют координаты документа и не зависят от расположения окна.

## Проверка прототипа

Режим `--verify-ai <directory>` проверяет About, меню и настройки при 1x/2x, затем встроенный helper через настоящий STDIO и Unix-сокет. Сценарий включает дом, изменение окна, отмену, масштаб, прокрутку, FatBits, отключение управления во время работы, сохранение и повторное чтение `.mac`. PNG сервера сопоставляется с пикселями рисунка. Отчёты: `Mods.json`, `AI-Control.json`, `AI-Canvas.png` и снимки окна.

Основа настройки подключения: [официальная документация MCP для Codex](https://developers.openai.com/codex/mcp).

## Контракт прототипа

`draw_batch` принимает `actions` с типами `stroke`, `line`, `rectangle`, `oval`, `polygon`, `fill`, `text`.
Фигуры используют `x`, `y`, `width`, `height`, `filled`, `line_width`, `color`.
Линии, штрихи и многоугольники используют `points: [{x,y}, ...]`. Цвета: `black`, `white`, `gray`.
Текст использует `x`, `y`, `text`, `font`, `size`. Точка задаёт верхний левый угол.
Текст рисуется чёрным по прозрачному фону с исходным набором Mac Roman. Точная JSON Schema доступна через `tools/list`.

Пакет ограничен 128 действиями, 512 точками в одном действии, 2048 точками суммарно,
толщиной 1–16 пикселей, запросом до 256 КиБ и объёмом растровой работы.
Текст ограничен 1024 байтами и 20 строками по 80 символов. Весь пакет проверяется до изменения холста.
Новая запись отклоняется во время другого пакета, диалога, ручного жеста или операции 128K.

При обрыве соединения результат записи может быть неизвестен клиенту. Автоматического повтора нет.
Клиент читает `get_canvas` перед новым рисованием. Остановка helper не является командой отмены в редакторе.
Используйте Stop или выключите AI control.

За пределами прототипа остаются редактирование отдельных объектов, многоуровневая история,
анимация внутри одного штриха и удалённый сетевой доступ.
